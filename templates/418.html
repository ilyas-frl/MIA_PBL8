418 I'm a teapot

Je suis une théière

Vous avez demandé du café à une théière. Elle refuse, poliment.

Le 1er avril 1998, Larry Masinter publie la RFC 2324, un faux standard pour piloter des cafetières par Internet : le « Hyper Text Coffee Pot Control Protocol ». Il y prévoit un code de réponse pour les théières à qui l'on demande du café : 418 I'm a teapot.

C'était une blague, mais les développeurs l'ont adoptée et beaucoup de logiciels la reconnaissent. En 2017, une proposition de le retirer de plusieurs outils a déclenché une campagne « Save 418 ». Le code est resté, et la norme HTTP actuelle (RFC 9110) le réserve pour qu'aucun vrai code ne prenne sa place.

Flask, lui, le connaît très bien : abort(418) suffit.
