La page {{ request.path }} existe bien, mais le serveur refuse de vous la donner.

Un code qui commence par 4 veut dire que c'est la demande qui pose problème : une page qui n'existe pas (404), une demande mal formée (400) ou, ici, un accès interdit (403). Le serveur, lui, fonctionne parfaitement.

Un code qui commence par 5 veut dire l'inverse : la demande était correcte, mais le serveur a planté (500). Là, c'est au développeur de réparer.
